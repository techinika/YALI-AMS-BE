# YALI AMS

Alumni Management System for YALI Rwanda Chapter

---

## Tech Stack

- **Backend:** Node.js, Express, Prisma, MySQL  
- **Frontend:** React, Next.js, Tailwind CSS  
- **Real-time:** Socket.IO  
- **Other:** Node-cron for scheduled tasks
